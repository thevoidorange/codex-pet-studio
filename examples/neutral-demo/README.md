# Neutral Demo

This directory demonstrates how a Codex Pet Studio project can move through approval gates without using a real person, pet, photograph, brand, or copyrighted character.

The fictional concept is **Signal Seed**: a small charcoal seed-like desktop creature inspired by an imagined pebble, a cursor, and the pause before a question.

No binary art or finished pet pack is included. The example is intentionally incomplete so it cannot be mistaken for a production-ready character.

## Try the workflow

Open this repository in Codex and say:

> Use the neutral demo to show me how you would move from inspiration to an identity lock. Stop before generating images.

Codex should:

1. read [`project-notes.md`](project-notes.md);
2. identify facts, interpretations, and open decisions;
3. draft an inspiration brief;
4. propose a small number of default-form directions;
5. stop at the identity approval gate.

## Why the example is neutral

- all inspiration is fictional and text-only;
- there are no private paths or identifying details;
- there are no external assets to license;
- the concept is generic enough to demonstrate process without prescribing an aesthetic.

For a real project, replace the notes with your own inspiration while keeping private inputs untracked.
