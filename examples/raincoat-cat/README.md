# Raincoat Cat

Raincoat Cat is the complete public example bundled with Codex Pet Studio. It
is an original, fluid black cat whose face and short limbs emerge from the same
opening in an oversized raincoat hood.

The example demonstrates the full Codex Pet v2 surface:

- nine distinct runtime states;
- fixed per-frame cadence and action lifecycle;
- sixteen continuous gaze directions;
- transparent, target-sized atlas cells;
- a real package manifest that can be validated by the Studio tools.

## Files

- `pet.json` — sanitized Codex Pet v2 manifest
- `spritesheet.png` — the approved 8 × 11 atlas
- `asset-attribution.md` — publication and rights record

## Preview

From the repository root, start the Previewer:

```bash
python3 .agents/skills/pet-studio/scripts/studio.py preview
```

Then open `http://127.0.0.1:8765/previewer/`. Raincoat Cat is the default
bundled Example.

Only the finished public package and its rights record are included here.
Private source images, prompts, design history, machine paths, and review
conversations are not part of the example.
